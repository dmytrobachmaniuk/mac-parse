# mac-parser

Telegram-бот, який стежить за вторинним ринком MacBook Air M1/M2 на OLX.ua.
Gemini переглядає фото й опис кожного оголошення та ставить оцінку угоді.

## Як працює

1. **Парсер OLX.** Кожні `SCAN_INTERVAL_MIN` хвилин бот проходить усі сторінки пошуку
   в категорії «Ноутбуки» за запитами `macbook air m1 / m2 / 2020 / 2022 / 15 2023`.
   Дані береться з `__PRERENDERED_STATE__` на сторінці пошуку, бо публічний API закритий (403).
2. **Фільтр регулярками.** Лише Apple Silicon M1/M2. Відсіює Intel (i3/i5/i7, роки ≤ 2019, A2179),
   чохли, коробки, запчастини, MacBook Pro, M3/M4 і ціни
   поза межами `MIN_PRICE_UAH…MAX_PRICE_UAH`. Витягає RAM/SSD, діагональ, % батареї та цикли.
3. **Ринкова ціна.** Медіана й P25–P75 серед активних оголошень з тією ж конфігурацією
   (чіп + RAM + SSD + діагональ).
4. **Gemini.** Отримує 4 фото, опис і ринкову медіану. Повертає структурований JSON: стан 1–10,
   дефекти на фото, комплект, ризики (iCloud/MDM, ремонт, стокові фото…), вердикт по ціні,
   оцінку угоди 1–10, висновок і питання до продавця. Повторний аналіз запускається лише
   для нових оголошень і тих, де змінилася ціна.
5. **Бот.** Розділи «M1», «M2» і «🔥 Топ». Картка складається з фото, характеристик,
   ціни відносно медіани, висновку AI та кнопки на оригінал. Гортання ◀ ▶,
   три види сортування (оцінка / ціна / нові) і кнопка «Переаналізувати».
   Пуш приходить, коли нове оголошення отримало оцінку ≥ `NOTIFY_MIN_SCORE`.

## Що вміє

- **Джерела:** OLX.ua і Prom.ua (лише вживані — за schema.org `UsedCondition`). Курс USD/EUR — з НБУ.
- **AI-оцінка угоди** (Gemini, кілька моделей по черзі через ліміти безкоштовного рівня): читає скріни
  з фото (батарея, цикли, серійник, iCloud/MDM), ставить 1–10, пише ризики й питання до продавця.
- **Сигнали продавця:** вік акаунта, «новий акаунт + ціна сильно нижча за ринок» (схема шахраїв),
  перекуп (3+ MacBook в оголошеннях), давно не заходив, верифікація.
- **Ринок:** медіана цін, які просять, і окремо — ціни реально проданих (оголошення, що зникли за 60 днів)
  та за скільки днів зазвичай продають.
- **Перевиставлення:** той самий ноутбук за серійником зі скріна або «зняв і виставив знову».
- **Telegram:** ✅ «підключено», 🆕 нова угода (оцінка ≥ `NOTIFY_MIN_SCORE`), 📉 ціна впала на 3%+
  (оцінка ≥ `BEST_MIN_SCORE`), ⚠️ парсер зламався / ✅ знову працює.
- **Сайт:** розділи Найкраще / M1 / M2 / Обране, фільтри, сторінки по 20, «В обране» і «Сховати»
  (на пристрої), світла/темна тема.
- **Надійність:** повтори запитів, keepalive проти вимкнення розкладу GitHub, попередження про відсутні секрети.

## Хмарний режим (GitHub Actions + Pages, безкоштовно)

Workflow `.github/workflows/scan.yml` кожні 30 хв: скан OLX → Gemini → пуші в Telegram про нові
оголошення з оцінкою ≥ `NOTIFY_MIN_SCORE` → сайт-каталог на GitHub Pages
(`https://<owner>.github.io/<repo>/`). База зберігається між запусками в гілці `data`.

Постійного бота в цьому режимі нема: Telegram — для пушів, перегляд — на сайті.
На повідомлення бот відповідає під час найближчого запуску (до ~30 хв).

Налаштування репозиторію (один раз):
1. Settings → General → Danger Zone → **Change visibility → Public**
   (Pages і безлімітні хвилини Actions безкоштовні лише для публічних репозиторіїв).
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Settings → Secrets and variables → Actions → New repository secret:
   `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`, `ALLOWED_USER_IDS`, `TELEGRAM_CHAT_IDS` (ваш chat id).
4. Actions → scan → **Run workflow** для першого запуску.

GitHub вимикає розклад, якщо в репозиторії 60 днів не було комітів у main — тоді просто
увімкніть workflow знову на вкладці Actions.

## Ключі

**Telegram-бот (2 хв)**
1. У Telegram відкрийте @BotFather → `/newbot`.
2. Вкажіть ім'я (будь-яке, напр. «Mac Hunter») і username, що закінчується на `bot` (напр. `my_mac_hunter_bot`).
3. BotFather надішле токен виду `1234567890:AAH...` — це `TELEGRAM_BOT_TOKEN`.
4. Свій user id дізнайтесь у @userinfobot (`/start` → рядок `Id`) і впишіть у `ALLOWED_USER_IDS`,
   щоб ботом не користувався ніхто інший.

**Gemini (2 хв)**
1. Відкрийте https://aistudio.google.com/apikey і увійдіть Google-акаунтом.
2. «Create API key» → оберіть існуючий Google Cloud-проєкт або дозвольте створити новий.
3. Скопіюйте ключ `AIza...` — це `GEMINI_API_KEY`.
4. Безкоштовного рівня вистачає: `GEMINI_RPM=8` тримає запити в межах лімітів. На безкоштовному рівні
   Google може використовувати запити для покращення моделей — для оголошень з OLX це не проблема.

Токен і ключ — секрети: лише в `.env` (він у `.gitignore`), не в коді й не в чатах.

## Запуск

```bash
cp .env.example .env   # вписати TELEGRAM_BOT_TOKEN і GEMINI_API_KEY
uv sync
uv run mac-parser bot
```

### У фоні (переживає закриття терміналу)

```powershell
.\scripts\start-bot.ps1   # запуск; повторний запуск перезапускає
.\scripts\stop-bot.ps1    # зупинка
Get-Content data\bot.log -Tail 30 -Wait   # лог
```

Бот працює, поки увімкнений комп'ютер; після перезавантаження Windows запустіть `start-bot.ps1` знову.

Корисне без Telegram:

```bash
uv run mac-parser scan --analyze 0   # тільки OLX, без AI
uv run mac-parser scan --analyze 5   # + AI для 5 оголошень
uv run mac-parser show M1 -n 5       # картки з БД у консоль
uv run pytest -q
```

База лежить у `data/macbot.sqlite3`.
